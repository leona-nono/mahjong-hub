# 麻将 H5 站点 · 执行工作清单（P0–P3）

> 配套 `mahjong-iaa-design.md` / `mahjong-solitaire-design.md` / `mahjong-prototype-tasks.md`。
> 本文件只列"做什么"，不写理由。优先级：先验证闭环 → 再扩量 → 后加层。所有数值 [PLACEHOLDER]。

## P0 · 验证最小闭环（30–45 天）— 生死线

**设计**
- [ ] P0-D1 牌面美术规范：万字省略 + 数字占牌面 1/3 + 生肖/脸谱特殊牌 + 色盲安全（图案+角标双维区分）。
- [ ] P0-D2 无障碍三件套：可调牌面尺寸、高对比模式、减弱动效开关。
- [ ] P0-D3 交互式 30 秒引导：高亮"自由牌"判定，首 3 关渐进教学（非弹窗长文）。
- [ ] P0-D4 可解关卡生成器：逆推保证可解 + 难度度量（死局所需 shuffle 次数 / 分支宽度），关卡排成平滑曲线。
- [ ] P0-D5 每日挑战（UTC 同种子）+ streak 每周 1 次冻结 grace + 离线进度。
- [ ] P0-D6 免费 Undo 基础次数（每关 3）+ 洗牌/提示/解围为付费或广告道具。

**工程**
- [ ] P0-E1 Next.js 15 脚手架 + `points_ledger` 只追加（余额 = SUM 流水）+ 防刷红线。
- [ ] P0-E2 `api/reward/verify` 广告 S2S 回调验签。
- [ ] P0-E3 指标埋点 + 漏斗看板：首牌点击耗时、每关死局率、shuffle/undo 分布、广告 offer 接受率 by cohort、PWA 安装率、Web Push 订阅率、streak 续期率。
- [ ] P0-E4 Feature-flag + 轻量 A/B（广告频率 cohort、onboarding 变体）。
- [ ] P0-E5 PWA：`manifest` + Service Worker，可"添加到主屏幕"。

**增长 / 合规**
- [ ] P0-G1 内容落地页（EN 为主）嵌入可玩模块；长尾词 cornerstone 集群起步。
- [ ] P0-G2 `ads.txt` + `seller.json` + GDPR/CCPA 同意管理上线。
- [ ] P0-G3 IVT 监控接入。

**变现**
- [ ] P0-M1 首日零广告 + cohort 渐进频率（前 3 session 近零，留存后渐进）。
- [ ] P0-M2 激励广告只绑工具（提示/洗牌/撤销/解围）；"看广告永久解锁牌背"主推 + $4.99 去广告 IAP 顺手。
- [ ] P0-M3 亚马逊联盟（US）挂链 + FTC 披露，主题内容旁放对应实物套装。

**P0 验收闸门**：匿名即玩 ≤60s；首局完成率 >50%；D7 留存 >25%（未达先修体验、不开买量）；广告 offer 接受率 >40%。

## P1 · 留存加固 + 买量起步（约 60 天）

- [ ] P1-D1 赛季 1 主题牌桌（如春节）+ 收集系统（牌背/牌桌图鉴）。
- [ ] P1-D2 内容→游戏奖励闭环：读主题文章解锁对应牌面/牌桌。
- [ ] P1-E1 Web Push 召回（每日挑战/赛季轻推）。
- [ ] P1-M1 广告频率 cohort 调参；Supporter $9.99 一次性包（可选 A/B）。
- [ ] P1-G1 YouTube/TikTok 短视频买量（便宜种子 + 小额补量）：素材放真实清牌画面；CAC 守门 + IVT 监控。
- [ ] P1-G2 PT-BR / ES / DE / FR / JA 内容本地化启动（先译内容不译 UI）。

**P1 验收闸门**：买量 CAC < web LTV 阈值；视频→试玩转化 >行业基准；D30 留存 >12%。

## P2 · 扩量 + 可选增量（约 90 天）

- [ ] P2-D1 mahjong connect 二维变体页（接 "mahjong connect" 关键词，非替换堆叠）。
- [ ] P2-D2 i18n 内容扩至 8–10 语种长尾。
- [ ] P2-D3 AI 麻将可选上线（仅当 P0/P1 数据显示需更深留存）：推倒胡 + 3 AI 难度/性格，复用消除积分；交叉导流入口 + 首登积分。
- [ ] P2-E1 App 壳评估（Capacitor 裹 H5 上架）：若 D7>30% 且月 UV 过门槛；store 合规口径 no-real-money。
- [ ] P2-D4 收集 metagame 深化（多章节主题牌桌库，内容联动）。

**P2 验收闸门**：connect 变体页自然流量占比；AI 麻将（若上）D7 与对战 ARPU；App 壳（若上）留存提升幅度。

## P3 · 规模变现（流量达量级后）

- [ ] P3-M1 Shopify 自营（建议月 UV ≥10 万再开）：品牌货（生肖/脸谱实物牌、主题周边）。
- [ ] P3-M2 多区域 Amazon Associates（US 跑通后再扩，遵守 180 天合格订单保号规则）。
- [ ] P3-D1 多 Episode 布局库 + 节日限时布局。
- [ ] P3-G1 联盟 + 自营 + 广告三变现层统一 dashboard，按区域/渠道算 LTV。

**P3 验收闸门**：电商 GMV/佣金占比达预期；三变现层合计 ARPU 达标；无单一层 >70%。

P0 未验证 D7>25% 前，不开买量、不加双游戏。
