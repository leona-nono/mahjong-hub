# 四人在线麻将 · IAA 模式机制设计文档

> 版本 v0.6 · 海外 H5 · 宏观定位「文化出海 + 服务明确的麻将需求人群」· 消除为**独立可闭环**主体（流量+留存+变现自洽），AI 麻将为可选增量 · 获客 = SEO（长尾+小众语种）+ YouTube/TikTok 短视频买量并行 · 变现 = IAA + $4.99 去广告 IAP + 亚马逊联盟（Shopify 待规模后）· 无玩家间实时对战（合规优先）· 银发向美术规范 · 所有未经 playtest 的数值均标 [PLACEHOLDER · 附假设与验证路径]

## 0. 设计前提与显式假设

| 维度 | 取值 | 说明 |
|------|------|------|
| 品类 | **单人 vs 3 AI 陪玩麻将**（推倒胡）为主 + 麻将消除（solitaire）休闲玩法为辅 | 用户已确认：不做玩家间实时对战，AI 陪玩为主，规避涉赌合规 |
| 平台 | 网站 H5，**面向海外**（英文站优先，多语言 i18n 后续展开） | 用户已确认 |
| 变现 | IAA 激励视频为主 + **$4.99 一次性去广告 IAP**（v0.4 新增，对标竞品空白档；H5 走 Stripe/Paddle 避开商店税）；不做订阅 | 用户确认 + 竞品活检修正 |
| 市场 | 海外（欧美为主，华人 + 西方休闲/好奇用户 + 银发族），宏观定位「文化出海」 | 用户已确认 |\n| 获客 | SEO（长尾 + 小众语种 cornerstone 文章）为主、**YouTube/TikTok 短视频买量为并行加速通道**（H5 落地摩擦低，视频导流 CTR 高） | 用户 v0.6 确认：可同步做短视频买量，不止纯 SEO |
| 目标用户 | **[已用竞品数据修正]** 55+ 银发为主、约 65% 女性（Vita/Blast/Journey 的共识用户画像），英文可玩；UI 按银发规范（大字号/高对比/点选优先） | 原假设 25-55 岁被头部产品数据推翻，已按银发重调字号与广告频次 |
| 单局时长 | **[假设]** 对战 8-12 分钟 / 消除单关 1-3 分钟 | 消除更短 = 更高频 IAA 露出与回访 |

**合规基线（先于一切设计）**：
- **去掉玩家间对战是本版最强合规护城河**：无玩家间价值转移 = 不构成在线赌博的 P2P 要件，落入海外 "social casino"（社交博彩）类目——该类目在欧美绝大多数市场合法（美国有大量判例支持）。积分仅作游戏内虚拟货币、不可提现 / 不可反向兑换 / 不可玩家间交易。
- 补三件事：① 数据合规（GDPR/CCPA，隐私政策 + 同意管理）；② 广告 SDK 年龄分级（标明 non-children）；③ **明确公示"对手为 AI，非真人"**——既合规又管理玩家预期，避免"以为在和真人对赌"的争议。
- 反例提醒：若日后做境内分发仍需版号 + 棋牌特许；若未来想加真人 PvP，等于重新打开涉赌审查，必须先过法务。

### 0.1 站点北极星定位（用户拍板，v0.5 收敛为"消除独立闭环 + 文化出海"）

**宏观使命**：以「文化出海」为品牌叙事、服务「明确的麻将需求人群」（海外华人 + 西方麻将好奇者 + 银发休闲族），用麻将主题产品承接这群人的需求，而非泛休闲流量。

**架构决策（v0.5 重大调整）**：用户已确认**不关心积分系统是否双游戏打通**。据此：

- **休闲消除 = 独立可闭环主体**：它自己就能完成「流量入口 → 留存 → 广告变现」的全链路，是站点的第一支柱。积分系统在消除内自成闭环（赚分、道具、外观），不依赖对战也能成立。
- **4 人 AI 麻将 = 可选增量**：只有当消除跑通、且数据显示需要更深留存时，才作为增量叠加；它**不是地基**，不决定站点生死。若上线，复用消除的积分体系即可，但这是"锦上添花"选项，非主线前提。
- **广告 + 电商 = 变现**：激励视频 + $4.99 一次性去广告 IAP 是主变现；电商 = **亚马逊联盟（Amazon Associates）先行**（零边际成本副变现，联名牌背/生肖脸谱 ↔ 实物麻将套装/书籍），**待站点流量达量级再开 Shopify 自营**（用户 v0.6 决策）。

> 据此收敛：不做游戏内旅行章节叙事、不做"每章配一篇博客"的重内容运营（Journey 式章节联动已砍）。SEO 只保留 cornerstone 文章集群作为**流量来源**，轻量承载，不绑定游戏章节——这是"更轻"的关键：把资源压在「消除独立跑通 → 文化出海叙事放大 → 广告电商变现」这条主线上，不养内容生产线，也不为打通双游戏硬上经济耦合。

> **原"单积分钱包双游戏协同"降级为可选项**：v0.4 的 pillar 6 曾是硬约束，现改为"若做对战，积分可复用，但消除闭环本身不依赖此"。详见 pillar 6 与 3.4 节修正。

## 1. Fun Hypothesis

**这游戏好玩的核心是：在信息不完全下做概率决策的紧张感，以及和牌瞬间"我算赢了"的智力优越感结算。**

麻将的乐趣不在操作（操作只是点牌），在**决策密度**——每一巡摸打都是一次"留哪张、防哪家"的微型赌博。网站版要保住这个内核；AI 陪玩同时解决两件事：① 不用凑人、秒开一桌；② 三个 AI 有性格、会"作妖"，把单机玩出"牌搭子"的社交感——这是 AI 陪玩模式的差异化乐趣，不是凑合。

## 2. Design Pillars（每条决策的过审标准）

1. **60 秒上桌**：从打开网页到打出第一张牌 ≤ 60 秒。H5 的命根子是零摩擦，注册、下载、教学全部后置。
2. **决策不被打扰**：摸打进行中零广告、零弹窗。广告只能出现在"局间"和"玩家主动求助"的时刻。
3. **赢了爽、输了有台阶**：输光不是终点，是激励视频转化率最高的黄金时刻。
4. **广告买不到牌运，但可以买建议**：对战里"看广告得出牌建议"可接受（PvE 场景，只影响玩家自己的决策、不伤害真人对手），但绝不给"看穿 AI 手牌"这种直接信息（破坏玩法）。meta 层奖励（积分、外观、表情、门票）照常给。消除游戏的道具是正常休闲机制。
5. **每个 source 有对应 sink**：任何积分产出必须能回答"这些分最后在哪被回收"。
6. **消除闭环自洽（双游戏打通降级为可选）**：消除的积分系统自成闭环（赚分、道具、外观全在消除内成立），不因未做对战而缺功能。原"单积分钱包贯通双游戏"是**可选项**——仅当 AI 麻将作为增量上线时复用同一积分体系，不是主线前提。

## 3. 核心循环（三层钩子）

### 3.1 Moment-to-moment（0-30 秒）
摸牌 → 读牌面（自己手牌 + 三家舍牌 + 副露）→ 打出一张 → 即时反馈（吃碰杠胡的按钮提示、音效、动画）。
**手感关键**：出牌响应 < 100ms，和牌动画要有"结算仪式感"（番型逐一翻出、金币滚动计数）。感觉不对先查这条反馈链，再怀疑机制。

### 3.2 Session loop（5-30 分钟）
进场选 AI 档位（底注档 + AI 难度，以积分为筹码）→ 对局（8-12 分钟，1 人 + 3 AI）→ 结算（输赢积分 + 番型展示 + **[广告点位：结算翻倍 / AI 出牌建议]**）→ 立即再来一局。
张力来源：积分水位——赢了想乘胜追击，输了想翻本。这个张力就是 IAA 的发动机，不需要额外造。

### 3.3 Long-term（小时-周）
每日签到 → 每日任务（打 3 局、胡 1 次自摸等）→ 段位/等级（纯荣誉，不带数值优势）→ 周榜（好友/同城）→ 外观收集（牌背、桌布、表情包——金币 sink + 广告解锁双通道）。
保留钩子的本质是"明天上线有事做"，不是"明天上线有便宜占"。

### 3.4 双游戏协同架构（增长视角）
- **消除游戏 = 独立可闭环主体（第一支柱）**：1-3 分钟一关、零教学、秒开即玩，是 SEO 文章与买量素材的最佳落地载体——用户被 "how to play mahjong / mahjong solitaire" 内容吸引，落地即玩消除，摩擦最低。它自己完成「获客 → 留存 → 广告变现」全链路，不依赖对战。
- **AI 陪玩麻将 = 可选增量（非地基）**：只有当消除数据证明需要更深留存时才叠加；上线时弹"想和 AI 牌搭子过两把？"交叉推广入口（带首登式积分奖励），复用消除积分体系即可。AI 陪玩零等待、随时开局，但它是"锦上添花"而非站点生死线。
- **积分打通 = 可选项（非硬约束）**：若 AI 麻将来上线，可复用消除的同一套积分（消除赚的分在对战下注、对战赢的分回消除买道具）；但这只是"复用"便利，消除闭环本身不需要它。一个账号、一条成长线是加分项，不是前提。
- **AI 陪玩是差异化卖点（若做）**：三个 AI 各有性格（贪吃型/保守型/话痨型）+ 表情/语音互动，制造"和牌搭子打牌"的氛围。这不是技术妥协，是产品定位——单机 + AI 陪玩在海外休闲市场是被验证的留存模型。

## 4. 积分经济系统：对庄（house）受控赔付模型

> v0.3 重大变化：去掉玩家间 PvP 后，经济从"玩家间零和 + 台费"变成**玩家 vs 庄（AI）的受控赔付**。每一局都是系统净产出或净回收，核心调控杆是 **AI 难度决定的玩家胜率（RTP）** + **台费抽水（house edge）**。

```
SOURCES（系统发分）                       SINKS（系统回收）
├─ 对局赢 AI：按底注×番型发分(受 RTP 控制) ├─ 对局输给 AI：底注被系统收走 [核心 sink]
├─ 消除通关得分 / 连击                     ├─ 台费抽水：玩家赢的每局抽 5%(house edge)
├─ 每日签到 + 任务                         ├─ 消除道具兑换(提示/撤销/洗牌/解围)
├─ 新客礼包 +积分                          ├─ 外观商城(牌背/桌布/AI 皮肤/表情)
└─ 激励视频奖励(主 source)                 └─ 破产出清(输光即流失)
```

**与 v0.2 的本质区别**：v0.2 玩家赢的钱来自其他玩家（零和），台费是出清口；v0.3 玩家赢的钱是系统印的、输的钱是系统销的——这是**单向阀**，必须靠 RTP < 50% + house edge 保证长期净回收，否则积分无限膨胀。

### 4.1 关键数值与 rationale（对庄模型）

| 变量 | 数值 | Rationale |
|------|------|-----------|
| 新客初始积分 | 5,000 [PLACEHOLDER] | 同 v0.2，够新手场下注约 25 局 + 消除道具体验 |
| 对战底注档 | 新手 200 / 普通 1,000 / 高手 4,000 / 大师 20,000 [PLACEHOLDER] | 同 v0.2 梯度；玩家选档即选风险 |
| **目标玩家胜率（RTP 核心）** | 新手场 ~55% / 普通场 ~48% / 高手场 ~42% / 大师场 ~38% [PLACEHOLDER] | **对庄经济的命门**。胜率随档位递减 = 高档场更难赢 = 更大 sink。靠调 AI 难度实现，不是靠运气。验证路径：每档位跑 10k 局 Monte Carlo 看实际胜率是否收敛到目标 |
| **台费抽水（house edge）** | 玩家赢的每局抽 5% [PLACEHOLDER] | 双重保险：即使胜率漂到 50%+，house edge 仍保证长期净回收。只抽赢家，输家不另扣 |
| 消除道具定价 | 提示 200 / 撤销 200 / 洗牌 300 / 解围 500 积分 [PLACEHOLDER] | 按 Shanghai 配对消除重做（v0.3 初稿的"加3步"是三消思维残留，已修正）；详见 `mahjong-solitaire-design.md` 第 6 节 |
| 破产线 | 积分 < 最低底注×2 触发 | 弹救济广告 |

**通胀监控（对庄版）**：监控两个指标——① 全服人均积分周增速 > 10% 亮红灯（比 v0.2 的 15% 更严，因为对庄模型通胀全靠系统、无玩家间转移缓冲）；② **各档位实际胜率 vs 目标胜率偏差 > 3 个百分点** = AI 难度要回调。红灯动作：上调 AI 难度 / 上调台费 / 上新高价外观。

### 4.2 AI 陪玩系统（取代"机器人补位"）
- 三个 AI 同桌，**性格 + 难度分离**：性格（贪吃/保守/话痨）只影响表情与选牌风格，难度（弱/中/强）决定胜率贡献。档位越高，强 AI 占比越大。
- **AI 决策服务端权威**：AI 的摸打由服务端计算，客户端只收结果——防客户端被改后"喂"AI 弱牌。
- **公示"对手为 AI"**：UI 明示三个对手是 AI 牌搭子，管理预期 + 合规。

### 4.3 跨游戏平衡红线
- 同 v0.2：消除单日产出设软上限防 farm；对战积分可买消除道具但不能买"直接过关"。
- 新增：对庄模型净回收必须为正（RTP×(1−台费) < 1），否则积分只增不减——这是对庄经济的存在前提，每周对账一次。

## 5. 激励视频点位矩阵（IAA 核心 · 双游戏）

原则：**广告出现在"玩家想要"的时刻，不是"系统想播"的时刻。** 消除游戏天然带"卡关/失败"高意图时刻，是 IAA 主发动机；对战承担留存与积分下注。

**AI 陪玩对战点位**

| # | 点位 | 触发时机 | 奖励 | 每日上限 | Rationale |
|---|------|----------|------|----------|-----------|
| 1 | **破产救济** | 积分 < 最低底注×2 | +1,000 积分 [PLACEHOLDER] | 3 次 | 流失最高点，续命非打扰，行业最高接受度 |
| 2 | **结算翻倍** | 赢局结算页 | 本局积分收益 +50% | 5 次 | 胜利峰值，只给赢家 |
| 3 | **每日转盘** | 签到后 | 免费 1 次，看广告再转 1 次（200-2,000 积分 + 外观碎片） | 2 次 | DAU 启动器 |
| 4 | **连败保护** | 连输 3 局 | +800 积分 + 表情 | 1 次 | session 终止高危 → 变曝光点 |
| 5 | **AI 出牌建议** | 玩家轮到出牌、主动点"提示" | 看广告得一次"建议出哪张" | 每局 3 次 | PvE 专属、可接受（只影响自己决策）；**红线：绝不能演变成"看穿 AI 手牌"** |

**消除游戏点位（IAA 主发动机，高频短局）**

| # | 点位 | 触发时机 | 奖励 | 每关/每日上限 | Rationale |
|---|------|----------|------|----------|-----------|
| 6 | **卡关复活** | 步数耗尽未清 | 看广告原地复活续步 | 每关 2 次 | 消除最强意图时刻，完播率最高，IAA 主力曝光位 |
| 7 | **免费道具** | 主动求助（洗牌/提示） | 看广告得一次临时道具 | 每关 3 次 | 与"花积分买道具"并存，双通道；制造"先白嫖再付费"的转化漏斗 |
| 8 | **每日消除宝箱** | 每日首登消除页 | 看广告开额外宝箱 | 每日 2 次 | 消除侧 DAU 启动器 |

### 5.1 全局广告纪律
- **局内零主动广告（对战）**：摸打进行中、等待 AI 操作时，系统不主动弹任何广告。**玩家主动求助**（点"提示"求出牌建议）触发的激励视频属玩家发起，不违反该红线——与消除的求助道具同性质。系统绝不能在玩家思考时主动打断。
- **全局冷却**：任意两个广告点位之间最小间隔 60 秒，防"广告连播"。
- **首日零广告**（v0.4 新增）：新用户首日（或前 5 关）不出任何广告，先建立产品认知再变现——Vita 验证的长线打法，空窗由积分新手礼包承接。
- **DAU 人均曝光目标**：8-15 次/日 [PLACEHOLDER]，其中消除游戏应贡献 60%+（高频短局天然露出多）。低于 8 养不活服务器，高于 20 留存第一周崩。验证路径：分桶看 7 日留存 vs 人均曝光次数曲线。
- **激励完成率红线**：弹出后玩家点"看"比例 < 40% = 奖励不够诱人或时机不对，调奖励不调文案。

### 5.2 收入侧粗算模型（用于立项判断，非承诺）
```
单日广告收入 ≈ DAU × 人均激励视频次数 × 完播率 × eCPM(美元) ÷ 1000
```
海外休闲棋牌 eCPM 通常低于国内（欧美约 $8-25，亚洲偏高），春节/圣诞前后上扬。这行公式是判断"DAU 要到多少才回本"，不是收入承诺——用美元计，别直接套人民币 eCPM。

## 6. 系统交互矩阵（打架风险提前暴露）

| 系统 A × B | 判定 | 说明 |
|------------|------|------|
| 破产救济 × 场次进阶 | acceptable | 救济分只够新手场，玩家必须重新爬档——设计意图内 |
| 结算翻倍 × 台费抽水 | intended | 翻倍部分也要抽 5%，否则等于开了 5% 的通胀后门 |
| 连败保护 × 破产救济 | acceptable | 两个点位可能同局触发，共用 60 秒全局冷却，先弹连败保护 |
| 机器人 × 结算翻倍 | **监控** | 对庄模型下每局都是系统净产出/回收，翻倍积分计入通胀监控；实际胜率超目标 3pp 时翻倍奖励减半 |
| AI 出牌建议 × 公平 | acceptable | PvE 场景，建议只影响玩家自己决策；红线是绝不能演变成"看穿 AI 手牌" |
| 转盘外观碎片 × 商城 | intended | 碎片只能合成、不能购买，制造"差一点就齐了"的回访钩子 |
| 消除道具兑换 × 积分通胀 | acceptable | 道具是消除侧核心 sink；若消除任务刷分过猛，上调道具定价压通胀 |
| 消除复活广告 × 全局冷却 | intended | 同局多次复活共享 60 秒冷却，防"看广告续命"成瘾 |

## 7. Playtest 失败信号（先定义坏掉长什么样）

| 信号 | 定义 | 坏掉的意思 |
|------|------|-----------|
| A（致命） | 对战次日留存 < 25%，或 60 秒上桌率 < 80% | 核心循环或新手路径有问题，停广告优化，先修体验 |
| B（警告） | 人均激励视频 < 5 次/日，且破产救济占比 > 60% | 玩家只有在没选择时才看广告——奖励结构失衡，不是广告位不够 |
| C（观察） | 全服人均积分周增速 15-25% | 轻度通胀，上调台费/道具定价 1-2 个点观察一周；> 25% 升级新外观 sink 紧急排期 |
| D（增长） | SEO 落地页跳出率 > 70%，或 短视频 CAC > web LTV 阈值，或 试玩→注册 < 30% | 漏斗断裂：内容流量接不住（修落地页）、买量不划算（停投调素材）、或落地摩擦过高。消除→对战转化 < 8% 仅作可选增量信号，不判主线生死 |
| E（经济） | 各档位实际胜率 vs 目标偏差 > 3pp，或全服人均积分周增速 > 10% | 对庄模型失稳：AI 难度漂移或台费不够，回调 AI 难度 / 台费 |

## 8. 首版范围建议（别贪）

**做（消除主线，优先）**：麻将消除休闲玩法、消除道具兑换（提示/撤销/洗牌/解围）、消除侧广告点位（卡关复活/免费道具/每日宝箱）、消除独立积分闭环、签到+任务、基础外观商城、SEO 内容页（cornerstone 文章 + 消除试玩落地）。
**做（AI 麻将，可选增量）**：仅当消除数据证明确需更深留存时叠加——推倒胡单玩法、3 个 AI 难度档、3 AI 陪玩（性格+难度）、对战广告点位 1/2/3/4/5（含 AI 出牌建议）、台费抽水（house edge）；可复用消除积分体系，但非前提。
**不做**：**玩家间实时对战（v0.3 明确砍掉，合规优先）**、好友房、段位赛、插屏广告、多玩法（血战/换三张留到 v0.4）、境内分发。

## 9. 海外增长飞轮：SEO + 短视频买量 → 消除接住 →（可选）对战

**获客双通道（v0.6 确认）**：

- **通道 A · SEO（长期地基，低成本）**：长尾词 + 小众语种（葡/西/德/法/日）cornerstone 文章集群，新站排得动的都是长尾与非英文；每篇文末嵌消除试玩模块，内容即落地。
- **通道 B · YouTube / TikTok 短视频买量（并行加速）**：短平快演示"一局消除""生肖牌面""文化冷知识"，视频 CTR 高、H5 落地**摩擦低于 App**（无商店安装步），适合低成本拉新。买量须守 LTV > CAC 纪律——web 端 LTV 低于 App，故 CAC 必须压得很低（靠短视频自然传播 + 小额投放），不追贵流量。

**飞轮结构（消除独立闭环为主，对战为可选叠加）**
```
[SEO 长尾/小众语种 文章]  ┐
[YouTube/TikTok 短视频]   ├─→ 着陆 消除试玩落地页(零摩擦,1关即玩)
                           │      → 消除玩几关, 攒首笔积分, 看广告/买道具 (IAA 主变现闭环)
                           │      → [可选] 消除3关后轻量弹"和AI牌搭子过两把?" 入口(对战为增量)
                           ┘
```

**H5 粘性缓解机制（用户核心担忧：H5 无 App 排他性与强粘性）**
H5 确实缺"桌面图标 + 一键打开 + 系统级推送"的天然留存力，用以下机制补：
1. **PWA 可安装**：`manifest.json` + Service Worker，让用户"添加到主屏幕"——把缺失的桌面图标补回来（iOS/Android 都支持）。
2. **Web Push 召回**：首次游玩引导订阅推送，每日挑战/赛季活动到点轻推，近似 App 的 re-engagement。
3. **每日挑战 streak（最强留存钩）**：UTC 同种子 + 连续天数奖励，制造"断一天就前功尽弃"的损失厌恶——这是 web 端对抗低粘性的最有效单一机制，优先级 P0。
4. **签到+任务+赛季收藏**：轻量日常理由（已设计）。
5. **匿名可玩、注册后并入**：降低首访门槛，但用积分/外观进度引导注册，把"游客"变"账号"，削弱 H5 的易流失性。

**各环设计要点**
| 环节 | 机制 | 监控指标 | 坏掉信号 |
|------|------|----------|----------|
| SEO 内容 | 长尾 + 小众语种 cornerstone + 内链 + 外链；文末嵌试玩 | 自然流量周增速、跳出率 | 跳出率 > 70% = 内容与落地不符 |
| 短视频买量 | 演示型短视频 → H5 落地页；守 LTV>CAC | CAC、视频→试玩转化率 | CAC > web LTV 阈值 = 停投调素材 |
| 消除落地 | 即玩不强制注册；匿名可玩，注册后并入 | 试玩→注册转化 | < 30% = 落地摩擦过高 |
| [可选] 交叉导流 | 消除 3 关后弹对战入口 + 首登积分 | 消除→对战转化 | < 8% = 入口/奖励不对（仅当对战上线时看） |
| 粘性 | PWA 安装率、Web Push 订阅率、每日挑战 streak 留存 | D7/D30 留存、streak 续期率 | D7 < 25% = 粘性机制失效 |

**关键立场**：消除是**独立可闭环主体**——它的存在意义首先是"自己接住流量、自己变现"，不是"导去对战"。对战交叉导流是可选增量（v0.5 降级）。若数据出现"消除 DAU 高、广告变现健康"即已跑通主线；对战转化低不代表飞轮断，只是增量未启动。

> 电商变现（详见 4.x / 北极星）：**亚马逊联盟（Amazon Associates）先行**——在内容页与牌面主题（生肖/脸谱/节日牌背）旁挂联名叫"对应实物麻将套装/书籍"的联盟链接，零边际成本；待月 UV 达量级（[PLACEHOLDER] 建议 ≥ 10 万/月再评估）再开 Shopify 自营品牌货。联盟需遵守 FTC/Amazon 披露要求 + 各区 Associates 账号资质（含 180 天内产生合格订单的保号规则）。
