# 国标麻将（MCR）81 番实现记录

## 规则基线

- 版本：Mahjong Competition Rules（EMA 英文版 / Green Book 的 81 项计分表）。
- 产品确认：四人、144 张、花季牌补花、8 分起和。
- 花季牌：每张计 1 分；**不计入** 8 分起和门槛。

## 已实现（本轮）

1. `lib/mahjong/mcr-catalog.ts` 以官方 1–81 编号建立完整计分目录，保留每项的分值和基础排除关系。
2. 计分器将已具备判定的项目映射回该目录，并应用可直接确定的“高番排除已包含低番”规则。
3. 修正小三元为 64 分；修正门清：放铳和为“门前清 2 分”，自摸和为“完全门前清 4 分”，不重复叠加自摸与门清。
4. 国标总分不再错误封顶为 88；88 是单个番种的最高值，不是手牌总分上限。

## 仍未实现为赛事裁判的部分

- 81 项中尚未具备独立牌型检测的项目；目录存在不表示该项目已自动判定。
- 同一手牌的多种拆分之间的“不可拆分”“不可同组重复使用”最优选择器。
- 吃、碰、杠、抢杠、海底等国标专属事件番及其完整时序。
- 国标竞赛的连庄、盘风、罚则、16 局赛制和比赛排名。

## 验证

- 81 项目录连续性及花牌例外。
- 小三元 64 分及其排除双箭刻 / 箭刻。
- 完全门前清不与自摸、门前清重复计分。
