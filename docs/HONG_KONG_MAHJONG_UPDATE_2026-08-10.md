# 香港麻将更新记录（2026-08-10）

## 本次完成

- 新增独立的香港四人麻将桌面组件，采用横向四人牌桌、四面牌墙、中央局况盘、牌河与玩家手牌布局。
- 使用项目自有香港麻将牌面资源，修正万、筒、索、风牌和箭牌的文件映射。
- 为 34 种基础牌生成独立的 1.8 倍有效牌面展示资源；原图保留不覆盖。香港规则实际排除白板，因此牌墙使用 33 种、共 132 张牌。
- 香港规则排除梅、兰、竹、菊、春、夏、秋、冬和白板；花牌、季节牌及白板不会进入香港牌墙。
- 增加香港麻将三番起胡校验，区分“牌型完成”与“达到最低番数的合法胡牌”。
- 修复玩家合法自摸后未显示胜利的问题；现在会自动结算并显示胜者、番数、牌型和支付结果。
- 增加洗牌、摸牌、出牌、吃、碰、杠、胡的本地 Web Audio 音效。
- 增加出牌粤语播报，并优先调用浏览器或操作系统的 `zh-HK` / Cantonese 语音。
- 增加音效开关、难度选择、提示、新局、暂停、计分提示和全屏入口。
- 修复认证状态与积分状态的服务端快照不稳定问题，消除相关 React 开发期告警。

## 验证结果

- TypeScript：通过。
- Vitest：5 个测试文件、99 项测试全部通过。
- 浏览器验收：新局、玩家出牌、AI 连续回合、返回玩家回合均正常。
- 牌面验收：14 张手牌保持单排；展示图片使用 `tiles-display` 资源；页面没有运行时错误。
